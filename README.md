# ValutaTradeHub

Консольная утилита для управления портфелем валют с автоматическим обновлением курсов из внешних API (CoinGecko и ExchangeRateAPI).

## 📋 Требования

- **Python** 3.13 
- **uv** - менеджер пакетов и окружений

## 🚀 Быстрый старт

1. Установка зависимостей
```bash
uv sync
```

2. Запуск
```bash
 uv run python -m valutatrade_hub.main
 ```

примечание: первый запуск может быть долгим, т.к курсов валют не существует.

## 🔑 Ключи API
Создайте файл **.env** в корне проекта со следущим содержимым:

*COINGECKO_API_KEY=ключ_coinсgeck*
*EXCHANGERATE_API_KEY=ключ_exchangerate*


## 🤖 Запуск парсера
1. Сначала необходимо запустить основное приложение
2. Затем выполнить 
```bash 
parser [--interval N]
```
